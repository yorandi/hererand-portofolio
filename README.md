# Software Engineer Portfolio

Dark, minimal, responsive portfolio built with Next.js App Router, TypeScript, and Tailwind CSS.

## Quick start

Requirements: Node.js 20.9+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

- Update the email and social URLs in `src/data/portfolio.ts`.
- Add your real CV at `public/cv.pdf` if you want the CV button to work.
- Replace project demo links with verified live URLs.
- Review every project description so it matches the current implementation.

## Deploy to Vercel

Push the repository to GitHub, import it in Vercel, and deploy with the default Next.js settings.
